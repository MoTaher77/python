# محفظتي — محفظة إلكترونية على غرار جيب

FastAPI + SQLite + واجهة ويب عربية (RTL).

الميزات: تسجيل برقم الهاتف ورمز سري، إيداع، سحب، تحويل بين المستخدمين، سجل العمليات، دفع فواتير، شحن رصيد.

## التشغيل
    pip install -r requirements.txt
    uvicorn wallet.main:app --reload
ثم افتح http://localhost:8000

## الاختبار
    pytest

ملاحظة: الإيداع هنا تجريبي (مباشر). في الإنتاج يجب ربطه ببوابة دفع/وكلاء، مع OTP، وHTTPS، وتحديد محاولات الدخول، وترخيص مالي.
